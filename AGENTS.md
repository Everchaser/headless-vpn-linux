# Инструкции для агентов

Работай из корня репозитория. Прочитай [SKILL.md](SKILL.md), затем [инструкцию развёртывания](docs/deploy.md) или [эксплуатацию](docs/operations.md). Новый сервер, изменение маршрутов и тесты на уже работающем сервере — разные действия.

- Не останавливай VPN, не трогай маршруты и не перезагружай хост без явного согласия оператора. Перед переключением проверь возможность отката из консоли.
- Не читай и не публикуй приватный `catalog.json`, подписки, ключи, machine-id и содержимое сырых журналов. Подписку вводит оператор в скрытом терминальном запросе. Тесты используют только синтетические данные.
- Для изменений запускай `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -q` и указывай, что реально было проверено. Интеграционный тест в [README.md](README.md) не поднимает TUN.

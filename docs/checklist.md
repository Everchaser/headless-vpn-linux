# Чек-лист нового сервера

- [ ] Есть независимая консоль; записано, как вернуться к прежней маршрутизации.
- [ ] systemd и `/dev/net/tun` доступны; подтверждены физический IPv4 uplink и отсутствие иных туннелей/IPv6-маршрутов, обходящих этот профиль.
- [ ] Проверены архивы ядер, версии и базовый HTTPS до изменений.
- [ ] `--stage` завершился без запуска служб; код и шаблон принадлежат root, state доступен только сервисному аккаунту.
- [ ] Ссылка введена через скрытый запрос. Если нужен HWID, разрешено отдельное устройство; кабинет провайдера показывает его.
- [ ] Синтаксис и хотя бы один узел прошли тест. Для проверки резерва есть минимум два доступных узла.
- [ ] Оператор явно разрешил переключение; чужого TUN нет.
- [ ] TUN, SOCKS и таймер запущены; несколько HTTPS-проверок успешны в течение минимум трёх минут; новый SSH-сеанс и прикладные сервисы проверены.
- [ ] Публикация следующего поколения: журнал подтвердил `Generation applied`, TUN остался активен, egress восстановился.
- [ ] Проверен контролируемый отказ выбранного upstream и восстановление на стенде. Не выдавать обычное обновление подписки за failover.
- [ ] Согласованная холодная загрузка: TUN и реальный HTTPS работают без входа в графический сеанс.
- [ ] Проверены остановка/откат из консоли и сохранность приватного state.
